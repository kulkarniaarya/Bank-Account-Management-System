# 🏦 Bank Account Management System

A Python-based Bank Account Management System that manages bank accounts and supports basic banking operations using SQLite.

## 🚀 Features

- Create a new bank account
- Deposit money
- Withdraw money
- Check account balance
- View account details
- PIN-based authentication
- Transaction management
- SQLite database integration

## 🛠️ Technologies Used

- Python
- SQLite
- SQL
- Git and GitHub
